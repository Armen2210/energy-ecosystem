# Материалы кейса: БТП в блок-боксе, Мелитополь

Кейс добавлен в портфолио в черновике PR №64. Это первый из трёх новых объектов.

## Подтверждённые сведения

- Объект — эргономический модуль патологоанатомического отделения Мелитопольской областной больницы.
- БТП «Энерголайн» обслуживает отопление и горячее водоснабжение.
- Блок-бокс разместили отдельно из-за отсутствия места для теплового пункта на объекте.
- Габариты из исходной записи — 4660 × 2260 × 2800 (высота). Для карточки размеры интерпретированы в миллиметрах.
- Работы выполнены в 2026 году. ООО «Энергоэффект» выполнило проектирование, изготовление, монтаж и пусконаладку под ключ. Изготовление заняло 3 месяца.
