## Повторяемая подготовка фото

Из `ee_site/frontend`, Python 3.12 и Pillow 12.3.0 (для воспроизводимого кодека —
та же версия Pillow/libwebp):

```bash
python -m pip install Pillow==12.3.0
python scripts/optimize-about.py
```

EXIF Orientation применяется до очистки метаданных. Встроенные профили преобразуются
в sRGB; свежие RGB-копии сохраняются без EXIF/GPS/XMP/ICC. Цвета не меняются
генеративно. Нет апскейла или кадрирования; и страница, и viewer показывают полный
кадр, включая всех участников юбилея. Запись производных атомарная, оригиналы
не изменяются. Повторный запуск даёт одинаковые имена, набор файлов и SHA-256.
small (длинная сторона 600) используется на mobile и в компактной галерее;
page (1200) — на более крупных экранах/высоком DPR; large (до 2000) — только viewer.
`srcSet` содержит реальные ширины, sizes соответствует компоновке. Верхний портрет
загружается обычно, остальные фото lazy; размеры резервируют место.

## Проверка

Итог: `npm test` — 40 passed; lint — passed; build — 19 public pages + 404;
`npm run test:prerender` — 7 passed; `git diff --check` — passed.
About browser runner — 17 групп проверок; existing lead-draft runner — 20 групп
на 1440/360 px, с перехваченными API/Метрикой. Для последнего использовалась
отдельная сборка `/tmp/ee-about-analytics` с явно включённым тестовым флагом;
основной dist сохраняет выключенное состояние по умолчанию.


```bash
npm test
npm run lint
npm run build
npm run test:prerender
# Playwright устанавливается отдельно от зависимостей приложения:
PLAYWRIGHT_MODULE=/workspace/.browser-tools/node_modules/playwright/index.mjs \
CHROME_PATH=/usr/bin/chromium node scripts/about-browser.mjs
```

Браузерный runner читает актуальный dist и перехватывает все запросы: только
локальные файлы и mock API; реальных заявок, SMTP или событий в production нет.
Артефакты по умолчанию `/tmp/ee-about`, переменная ABOUT_OUTPUT меняет каталог.
Копии итоговых скриншотов и JSON предоставлены в `/workspace/ee-about-review`.

Проверены 360, 390, 768, 960, 1024 и 1440 px: нет горизонтального overflow,
пересечений логотипа/навигации/телефона; все семь изображений загружаются,
есть alt, размеры и подходящий srcSet. Desktop/mobile-скриншоты просмотрены.
Проверены семь открытий, focus trap, Escape, кнопка закрытия, backdrop (нажатие
на фото не закрывает), стрелки, браузерный touch swipe, фокус и прокрутка после
закрытия, SPA-unmount, низкий экран 960×320 и reduced-motion.
Проверены состояния ожидания, ошибки и повторной загрузки.

Проверены header/footer, прямой вход/reload, Back/Forward, активный `/about`,
CTA/позиционирование контактов, сохранение полей и двух File после перехода
на `/about` и обратно, настройки cookies, существующие hash-секции главной,
изделие, услуга и открытие/закрытие кейса. Метаданные корректны; hydration/runtime
ошибок нет. Без JavaScript доступны все основные факты, подразделения и фото.
Sitemap сохраняет единственный `/about` и 19 публичных маршрутов.

По сети: после просмотра всей страницы увеличенные файлы не запрашиваются.
Открытие портрета добавляет ровно один `dsc05801-large-*.webp`; mobile использует
small-варианты при DPR 1. Точные URL/currentSrc/размеры и запросы до/после — в
report.json. На отдельной сборке с включённой аналитикой и mock Метрики проверены SPA hits;
все семь открытий фото не отправляют `case_open`. Реальный счётчик не загружался.
Большие URL присутствуют в bundle, но не в src/srcSet страницы и
не предзагружаются. Все 7 исходников проверены по SHA-256: оригинальные байты
неизменны и отсутствуют среди всех файлов dist независимо от имён сборщика.
21 публичная копия проверена на отсутствие EXIF, GPS, XMP и ICC.

Ограничения: автоматизация выполнена в Chromium, не на физических устройствах,
Safari/Firefox и не с экранным диктором. Реальная индексация, права/согласия,
истинность имён, production-сервер и приём Метрики этим не подтверждаются.
Временные имена требуется заменить перед публикацией. Остальные этапы аудита и
нерешённые вопросы остаются в content-audit; публичные документы не добавлялись.
