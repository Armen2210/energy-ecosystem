# Телефон заявки и документы на продукцию

Поле телефона предназначено для номеров с кодом +7. При фокусе в пустом поле появляется +7; далее доступны десять цифр номера. Начальные 8 и 7 при наборе трактуются как префикс и заменяются на +7. Пустой префикс не сохраняется как содержимое черновика. При вставке полного номера допускаются 10 цифр, 11 цифр с 8/7, пробелы, скобки и дефисы. Полный вставленный номер заменяет содержимое поля, лишние цифры обрезаются; при обычном наборе вставка сверх лимита блокируется без потери последней цифры. Выделенную цифру можно заменить, префикс защищён от удаления Backspace/Delete. Другой международный код и добавочный номер текстом отклоняются с пояснением. Неполный номер нельзя отправить.

Автозаполнение обрабатывается при изменении и потере фокуса. Перед отправкой форма дополнительно читает фактический DOM, чтобы принять полный номер даже при автозаполнении без React-событий; неверная длина не передаётся в API. Серверная нормализация сохранена без изменений: после расчёта прежнего fingerprint, чтобы не нарушать повтор старых запросов; экспорт Calltouch также обрабатывает номера ранее сохранённых заявок. Сервер по-прежнему совместим с прежними клиентами, ограничение ввода относится к публичной форме.

Документы копируются побайтно без изменения содержания. PDF открываются в новой вкладке, две исходные декларации DOCX скачиваются в Word. Имена и изготовители указаны по содержимому, даты не проверялись по реестрам; публикация не является проверкой юридической действительности.
