# Телефон заявки и документы на продукцию

Телефоны из 10 цифр без международного префикса получают +7. Для 11 цифр с 8 или 7 используется +7. Остальные международные номера не переписываются. Форма нормализует завершённый номер при потере фокуса и перед отправкой, читая фактическое значение DOM для автозаполнения. Сервер нормализует сохраняемый номер после расчёта прежнего fingerprint, чтобы не нарушать повтор старых запросов; экспорт Calltouch также обрабатывает номера ранее сохранённых заявок.

Документы копируются побайтно без изменения содержания. PDF открываются в новой вкладке, две исходные декларации DOCX скачиваются в Word. Имена и изготовители указаны по содержимому, даты не проверялись по реестрам; публикация не является проверкой юридической действительности.
