# Электронные ОЛ: контракт v1

Основа: `feature/ee-documents`, `d3dafac9b703dd26bab0b97cd0b3bb0dd393e7ef`.
Принятые публичные XLSX/PDF не меняются. `fields.json` содержит подписи, поля,
варианты, единицы, применимость и обязательность для ВНС/ПНС/БМК/БТП.
Имена полей веб-контракта не являются адресами ячеек Excel.

`POST /api/leads/`, multipart или form-encoded: необязательный **один** параметр
`questionnaires` — строка JSON `{version:1,items:[{product,schemaVersion:1,answers}]}`.
Примеры находятся в `examples/`. Без параметра прежний контракт не меняется.
Пустой/некорректный параметр, повтор изделия, неизвестные ключи, неприменимые
активные ответы и версии отклоняются с 400. Объекты JSON не допускают повторных
ключей. Ошибки: `questionnaires["pns.technical.jockey_flow"]`, для выхода —
`btp.collector_heating.outlets.<stable-id>.power`.

Секции БТП включаются независимо в `answers.selectedSections`; общие данные
обязательны для любого состава. Выключенные секции/ОЛ и неприменимые ответы
сохраняются только в браузерном черновике, не в payload/PDF. Полностью пустая
строка выхода не отправляется; строка только с настройками требует одного из
мощности/расхода/Ду. Идентификатор выхода сохраняется после удаления соседей.

Веб-перечисления имеют ровно варианты `fields.json`, API не угадывает синонимы.
Числа — десятичные строки с точкой или запятой (без exponent/NaN/Infinity).
Из бланков перенесены целые неотрицательные количества ПНС и диапазон 50–100%
для резервирования ТО. Для прочих величин бланки проверяют число, поэтому
дополнительные инженерные диапазоны не назначены. Температура может быть
отрицательной, 0 отличается от отсутствия. Защита ресурсов: до 64 символов на
число, |ввод| ≤ 10^15; это технический предел, не рекомендация подбора.

## Единицы

Выбрана **международная табличная калория (IT)**: 1 cal_IT = 4,1868 Дж,
1 Гкал_IT/ч = 4 186 800 000 / 3 600 / 1 000 = 1162,222222… кВт.
Это не термохимическая калория 4,184 Дж. Проверенный технический источник:
[SciPy constants, `_constants.py`, calorie_IT](https://github.com/scipy/scipy/blob/main/scipy/constants/_constants.py),
прочитан 01.11.2026; значения `calorie_th=4.184`, `calorie_IT=4.1868` сверены.
Первичный справочник для конвенций — NIST SP 811, Appendix B (прямой доступ к
сайту NIST из текущей среды ограничен, его чтение не заявляется).

1 м³ = 1000 л; 1 кгс/см² = 0,0980665 МПа (стандартное g = 9,80665 м/с²).
В UI хранится исходная физическая величина при переключении единиц, а не цепь
округлений. Неверный/незавершённый ввод не конвертируется и остаётся в поле.
Сервер принимает только `{value,unit}`, самостоятельно нормализует Decimal в
кВт/л/МПа. Для fingerprint точность 12 десятичных знаков базовой единицы;
ненулевые значения меньше 10^-12 сохраняются без превращения в 0. Ввод 1 Гкал/ч
и 1162,2222222222222 кВт эквивалентен по этой политике. Значения не предназначены
для автоматического инженерного расчёта или выбора оборудования.

## Снимок и повторы

Порядок изделий/выбранных секций канонизируется; порядок выходов сохраняется.
В fingerprint входят все принятые ответы ОЛ. Legacy-хеш без ОЛ не меняется.
`direction_type/slug` остаётся текущим контекстом; полный состав хранится отдельно.
Заявка, ОЛ, снимок контактов/описания, схема рендера и job записываются в одной
транзакции. PDF восстанавливаются из снимка, не текущего XLSX или React.
Файловая система не объявляется частью ACID БД. См. эксплуатационную инструкцию.

Один общий store заявки, sessionStorage `ee-lead-draft-v1`, 24 часа от последнего
содержательного изменения; просмотр/листание срок не продлевают. До этого этапа
store был только в памяти, старого persisted-формата контактов не существовало.
Существующие контакты в памяти не сбрасываются при добавлении структуры ОЛ.
Байты File и аналитические источники не сохраняются в этом store. После reload
нужно повторно выбрать файлы и подтвердить согласие; это сообщается пользователю.
Повтор после неопределённого ответа сохраняет submission id и signature. При
изменении снимка требуется явное подтверждение риска второй заявки.

## Зависимости

ReportLab 4.4.10 (BSD) — серверная генерация, в браузер не попадает. Требуется
системный DejaVu Sans (лицензия Bitstream Vera/DejaVu), встраивается в PDF.
Pillow/charset-normalizer — зависимости ReportLab. Redis/Celery/office не нужны.
Рендер ограничен subprocess: CPU 30 с, wall timeout 45 с, адресное пространство
512 МиБ, PDF до 5 МиБ. Один процесс worker выполняет одну работу за раз.
