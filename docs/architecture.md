# Architecture

## Общая архитектура экосистемы

Экосистема состоит из трех направлений:

1. Теплоучет — e-commerce.
2. ТД Энергоэффект — B2B lead capture.
3. Энергоэффект — engineering platform.

## Теплоучет

Существующий интернет-магазин.

Не дублируется в новых сайтах.

## ТД Энергоэффект

Архитектурная роль:

- публичный сайт;
- заявки;
- контент;
- кейсы;
- направления;
- контакты.

Backend должен оставаться простым.

## Энергоэффект

Архитектурная роль:

- публичный сайт;
- личный кабинет;
- проекты;
- документы;
- OCR;
- AI extraction;
- расчеты;
- CRM;
- 1С.

Backend ЭЭ должен проектироваться как ядро будущей платформы.

## Главная бизнес-сущность ЭЭ

Центральная сущность:

Проект / Заявка

Проект связывает:

- клиента;
- компанию;
- изделие;
- загруженные документы;
- распознанные данные;
- расчет;
- документы;
- КП;
- счет;
- CRM;
- статусы.
