# Architecture Decisions

## ADR-001. Разделение сайтов ТД и ЭЭ

Решение:

Сайты ТД Энергоэффект и Энергоэффект разрабатываются как отдельные проекты внутри общей экосистемы.

Причина:

- разные бизнес-роли;
- разная сложность;
- разные сценарии пользователей;
- разная backend-архитектура.

## ADR-002. Теплоучет не дублируется

Решение:

Новые сайты не должны копировать интернет-магазин Теплоучет.

Причина:

Теплоучет уже выполняет роль e-commerce.

## ADR-003. ТД остается простым B2B-сайтом

Решение:

Сайт ТД на первом этапе не получает сложные функции.

Он нужен для:

- доверия;
- лидов;
- заявок;
- переходов в экосистеме.

## ADR-004. ЭЭ проектируется как будущая платформа

Решение:

Backend ЭЭ сразу проектируется с учетом будущих модулей:

- личный кабинет;
- проекты;
- документы;
- OCR;
- расчеты;
- CRM;
- 1С.

Даже если эти функции будут добавлены позже.
