# Energy Ecosystem

Цифровая экосистема группы компаний:

1. ООО «ТД Энергоэффект»
2. ООО «Энергоэффект»
3. ООО «Теплоучет»

## Роли сайтов

### ТД Энергоэффект

B2B-сайт входа в экосистему.

Основные задачи:

- привлечение лидов;
- формирование доверия;
- сбор заявок;
- маршрутизация пользователей;
- презентация комплексной поставки.

### Энергоэффект

Сайт производителя и будущая инженерная цифровая платформа.

Планируемые задачи:

- презентация изделий;
- прием заявок на расчет;
- личный кабинет клиента;
- загрузка документов;
- OCR-анализ;
- расчетные процессы;
- генерация КП;
- интеграция с CRM;
- интеграция с 1С.

### Теплоучет

Существующий интернет-магазин инженерного оборудования.

Роль в экосистеме:

- e-commerce;
- каталог;
- карточки товаров;
- корзина;
- покупка оборудования.

## Главный принцип

ТД не дублирует Теплоучет.

ЭЭ не дублирует Теплоучет.

Теплоучет остается e-commerce-контуром.

ТД отвечает за B2B-лиды.

ЭЭ отвечает за инженерные решения и производственные продукты.
